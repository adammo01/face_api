## 三、为什么不同模式对抗强度差这么大?

### 人脸识别系统依赖的 3 类特征

| 特征 | 描述 | 对抗方式 |
|---|---|---|
| **landmark 几何** | 68/106 个关键点的相对位置(眼/鼻/嘴/下颌)| 在关键点处画大块色块 |
| **皮肤纹理** | 微观的皮肤纹路/毛孔/色斑 | 整脸模糊 + 打乱 |
| **整体轮廓** | 脸型、下颌、颧骨、额头 | 整脸色块覆盖 |

### 各模式覆盖特征情况

| 模式 | landmark 几何 | 皮肤纹理 | 整体轮廓 | 综合对抗 |
|---|---|---|---|---|
| gaussian | ✗(五官仍可辨) | △(模糊但保留脸型)| ✗ | 弱 |
| pixelate | ✗(块状但五官可辨) | △(同上) | ✗ | 弱 |
| solid | ✓(整块黑色) | ✓(无纹理) | ✓(无轮廓) | **最强** |
| landmark(只 5 红点)| ✗(只点 5 个小点,landmark 几何完整)| ✗ | ✗ | **最弱** |
| landmark_whole_face | ✓(红点覆盖整脸,扰乱 landmark 几何)| ✓(皮肤被红点遮挡)| △(脸型隐约可见) | 强 |
| **anti_face(新)** | ✓✓(**关键点大块黑色 + 红点网格**)| ✓(高斯模糊) | △ | **强(且美观)** |

### 关键洞察

- **`pixelate` 和 `gaussian` 失败的根本原因**:它们只"模糊了纹理",但**landmark 几何和脸型轮廓完全保留**。face_recognition、ArcFace、face++ 等系统对像素化/模糊有专门的训练鲁棒性,会在低分辨率下仍然识别。
- **`landmark` 只点 5 个红点最弱**:它只"打码了 5 个红点",其他 95% 的脸部信息(轮廓/皮肤/发型/眼型/鼻型/嘴形)全部保留 —— face_recognition 看的就是 landmark 几何 + 局部纹理,这里 landmark 几何**反而被打码成了强信号**。
- **`solid` 最强但视觉暴力**:纯黑块完全破坏所有特征。
- **`landmark_whole_face` 已不错**:整脸密集红点同时破坏 landmark 和纹理。
- **`anti_face` 升级版**:在 landmark_whole_face 基础上**额外在 5 个关键点上画 60×60 黑色块**,确保即使是 5 点 landmark 也被破坏。

## 四、`anti_face` 新模式实现要点

代码:`_bench/anti_face.py`

三层叠加(顺序很重要):
```
1. 整脸高斯模糊(ksize=51) → 破坏皮肤纹理
2. 关键点大块黑色矩形(60×60px @ 双眼/鼻/嘴) → 破坏 landmark 几何
3. 整脸密集红点网格(face_grid_step=12, dot_radius=3) → 扰乱全局 landmark
```

**参数可调**(API 暴露给前端):
- `occlusion_size`: 关键点遮挡块大小(默认 60px,可调到 80-100 强化)
- `blur_ksize`: 高斯模糊核(默认 51,7-31 更温和,51-101 更激进)
- `face_grid_step`: 红点间距(默认 12,8-14 可调)

**速度**:`anti_face/cv = 167.6ms`,`anti_face/ort = 113.2ms`(比原图略慢,因为多了一层高斯模糊)

**检出**:cv 检出 2 张脸,ort 检出 2 张脸,与现有 landmark_whole_face 一致
